## 1. Corrected release scope

The replacement `v0.1.33` keeps the same product and SDK versions while adding the corrections
required after withdrawal:

- exact Registry KodaX 0.7.77 and Node 22 toolchain alignment;
- canonical Agent Actor/Turn projection and monotonic Runtime/history reconciliation;
- root context, cumulative Session usage and prompt-cache diagnostics;
- shared Shell/profile-PATH behavior for Terminal and Coder command tools;
- F140 configurable main-window close behavior;
- F141 customer-selectable recommended Daemon / Embedded compatibility owner with one admission
  boundary, complete blockers, startup reconciliation, compensation, and restart;
- F142 conversation file actions;
- visible sent/restored image attachments and unambiguous context/compaction state;
- KodaX 0.7.77 split MCP/Extension/A2A configuration, SDK-backed non-destructive migration, and
  Settings source truth;
- preservation of every SDK-recommended underlying `kodax_manual` topic, including exact original
  body, aliases, and sources beneath same-id Space overlays; and
- Registry-only packaging, complete dependency closure, packaged native SQLite load, public-facade
  imports, and a real packaged application boot.

It does not update KodaX beyond 0.7.77, consume a local unpublished SDK, migrate Partner into the
Coder daemon, provide live owner failover, ship F137 document authoring, or claim signed/notarized
installers.
