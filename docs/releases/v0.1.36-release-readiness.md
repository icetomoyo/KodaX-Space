## Release decision

`v0.1.36` is a maintenance release that closes the post-`v0.1.35`
active-Session admission and history/live reconciliation gaps. It does not
assign or prematurely claim F137/F139; those features remain scheduled for
`v0.1.42`.

The release includes:

- exact Registry KodaX 0.7.82 resolution and lockfile SRI;
- a bounded admission boundary for send, interrupt, after-turn, Session
  switching, draft restoration, and history revalidation;
- exact `runId`/`turnId`, source-revision, cursor, and Session identity
  preservation through live events, snapshots, paging, reconnect, and late
  reads;
- renderer hydration and sidebar recovery that reject stale cross-Session
  events without dropping in-flight work;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, changelog, release design, regression
  guide, and in-app `kodax_manual`; and
- explicit retention of Issue 133, 136, 142, 143, 146, and 165 boundaries.
