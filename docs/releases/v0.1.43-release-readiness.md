## Release decision

v0.1.43 publishes the Runtime exit, output-segment, and filesystem-effect
convergence work already present on the release source line and updates every
current manual/document entry. The npm registry check confirms that KodaX
0.7.92 is the current `latest` release at preparation time. Release
preparation does not add a system business rule. Any CI-only adjustment
remains limited to tests, smoke probes, workflow configuration, or
documentation.

The release includes:

- exact npm Registry KodaX 0.7.92 resolution and lockfile SRI;
- local SDK `runtimeExitSettlement:1` plus `settleKodaXRuntimeExit()` for
  crash-resumable complete exit;
- SDK and connected Runtime `sandboxRuntime:4` plus `crashOutcomeModel:2`;
- `liveOutputSegments:1` as the only effective provider-output projection;
- fenced idle-daemon replacement and fail-closed busy/multi-client owners;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, changelog, feature
  design, regression guides, and in-app `kodax_manual`.
