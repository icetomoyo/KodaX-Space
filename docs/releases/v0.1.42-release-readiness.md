## Release decision

v0.1.42 publishes the causal transcript and KodaX alignment work already
present on the release source line and updates every current manual/document
entry. The npm registry check confirms that KodaX 0.7.88 is the current
`latest` release at preparation time. Release preparation does not add a
system business rule. Any CI-only adjustment remains limited to tests, smoke
probes, workflow configuration, or documentation.

The release includes:

- exact npm Registry KodaX 0.7.88 resolution and lockfile SRI;
- `actorSettlementConvergence:2` negotiation from SDK and connected Runtime;
- exact Session/Run/Turn ownership across canonical/live folding, delayed
  terminals, continued Runs, reconnect, and Ctrl+R;
- create-time provider/model continuity through daemon admission;
- bounded classifier-reason visibility and confirmed Session deletion feedback;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, changelog, feature
  design, regression guides, and in-app `kodax_manual`.
