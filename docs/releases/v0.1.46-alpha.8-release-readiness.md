# v0.1.46-alpha.8 release readiness

Date: 2026-09-08. Previous release: v0.1.46-alpha.7.

## Scope

- Pin the published KodaX 0.7.96-beta.3 in root/Desktop manifests and the lockfile.
- Fix Issue 210: manual compact waits for command echo and in-flight notice retry persistence before preflight, while showing the command immediately.
- Preserve SDK credential-connection recovery through Space's existing reconnect path.
- Package ASRT and dependencies from the exact SDK bundle; reject nested ASRT inside ASAR and verify physical WFP probe bytes.
- Synchronize workspace versions, diagnostics, changelog, READMEs, capability ledger, product/architecture/usage docs, user manual, feature and issue records, and kodax_manual.

## Qualification

Typecheck, application lint (excluding local untracked scratch diagnostics), production build, and Registry tarball/SRI/installed-byte verification passed locally. Full local npm test passed: 3298 passed, 13 skipped, 0 failed. GitHub matrix results must be verified on the release commit before declaring completion.

The GitHub build workflow covers Windows, macOS and Linux. CI covers both Windows and Linux E2E shards. The tag-triggered release workflow additionally requires lint, unit tests, all four installer targets, packaging/native/Worker smoke and Linux renderer boot before publishing. Existing gates are unchanged.

Real Provider automatic compaction and host WFP enforcement retain their manual acceptance steps in the [Issue 210 regression guide](../test-guides/ISSUE_210_v0.1.46_REGRESSION_GUIDE.md).
