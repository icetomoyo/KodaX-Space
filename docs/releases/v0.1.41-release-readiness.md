## Release decision

v0.1.41 publishes the provider-recovery compatibility work already present on
the release source line and updates every current manual/documentation entry.
The npm registry check confirms that KodaX 0.7.87 is the current `latest`
release at preparation time. Release preparation does not add a system
business rule. Any CI-only adjustment is limited to tests, smoke probes,
workflow configuration, or documentation.

The release includes:

- exact npm Registry KodaX 0.7.87 resolution and lockfile SRI;
- GLM-5.3 Zhipu Coding Plan defaults and effort mapping from the published SDK;
- ordered `provider.recovery` consumption for live, history, reconnect, and
  snapshot hydration paths;
- transcript parity before and after Ctrl+R without content-based deduplication;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, changelog, feature
  design, regression guide, and in-app `kodax_manual`.
