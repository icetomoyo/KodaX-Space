## Release decision

v0.1.37 is a maintenance release for the already-landed multi-Session
recovery and safe-close stabilization. It does not assign or prematurely claim
F137/F139; those features remain scheduled for v0.1.42.

The release includes:

- exact Registry KodaX 0.7.83 resolution and lockfile SRI;
- Session recovery that preserves project, surface, Session, request, and
  Runtime identity across hydration, switching, paging, and late events;
- safe-close recovery that keeps a visible progress surface until shutdown is
  proven and relaunches through a controlled path when Runtime authority closes;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, builtin skill guide,
  beginner guide, changelog, release design, regression guide, and in-app
  kodax_manual; and
- the test-only KodaX 0.7.83 compatibility expectation update.
