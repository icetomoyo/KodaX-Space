## Release decision

v0.1.38 is a maintenance release for the already-landed Session reactivation
correction and KodaX 0.7.84 runtime alignment. It does not assign or
prematurely claim F137/F139; those features remain scheduled for v0.1.42.

The release includes:

- exact Registry KodaX 0.7.84 resolution and lockfile SRI;
- the bounded Agent progress and same-owner Stop reconciliation contract;
- Session reactivation coverage that prevents a canonical history duplicate or
  misplaced newest turn;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, builtin-skill guide,
  beginner guide, changelog, release design, regression guide, and in-app
  `kodax_manual`; and
- package metadata and tracked icon-resource alignment for the release artifact.
