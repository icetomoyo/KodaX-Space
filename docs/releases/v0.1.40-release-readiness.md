## Release decision

v0.1.40 publishes the KodaX 0.7.86 sandbox and owner-reconciliation
maintenance line already present on `main`. Release preparation updates version
metadata, release documentation, and the in-app `kodax_manual`; it does not
introduce a new system business rule. Any CI-only adjustment must remain in
tests, smoke probes, or workflow configuration.

The release includes:

- exact Registry KodaX 0.7.86 resolution and lockfile SRI;
- SDK and Runtime negotiation of `sandboxRuntime:3`;
- packaged Electron/ASAR Windows Shell coverage for Issue 128;
- sandbox-first Runtime Shell fallback with the existing normal permission policy;
- atomic stale inline-owner recovery and retryable inline-owner cleanup;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, changelog, feature
  design, regression guide, and in-app `kodax_manual`.
