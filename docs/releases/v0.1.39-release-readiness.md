## Release decision

v0.1.39 is a maintenance release for the already-landed KodaX 0.7.85
alignment, Actor settlement convergence, Session journal epoch isolation,
unknown Run/after-turn behavior, exact Stop identity, input operation
deduplication, history/live reconciliation, and idle-exit client protection.
It does not claim unfinished F117/F138 work or add new system business logic
as part of release preparation.

The release includes:

- exact Registry KodaX 0.7.85 resolution and lockfile SRI;
- `actorSettlementConvergence:1` and `sessionEventJournal:1` capability gates;
- durable-unknown input admission, exact visible-Run Stop, journal-epoch
  watermarks, and canonical history/live protection;
- runtime idle-exit preservation when other Runtime clients remain connected;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, known issues, usage guide, beginner guide,
  changelog, release design, regression guide, and in-app `kodax_manual`.
