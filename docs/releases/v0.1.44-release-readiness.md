## Release decision

v0.1.44 publishes F145 native attention and the background-exit, canonical
history, Task Dock/Repointel, External Agent state, and Windows ACL recovery
work already present on the release source line. The npm Registry check on
2026-08-20 confirms KodaX 0.7.93 as `latest`. Release preparation changes only
version/dependency metadata, tests, release automation, and documentation; it
does not change system business logic.

The release includes:

- one native attention count per unread or action-required Session across the
  Windows taskbar/tray, macOS Dock, and supported Linux launchers;
- background continuation of admitted Windows complete-exit settlement, with
  elapsed progress on reopen and quiet ordinary success;
- exact npm Registry KodaX 0.7.93 plus actionable, fail-closed previous-boot
  Windows ACL recovery guidance;
- stable canonical page heads and live Task Dock/Repointel activity;
- normal empty and retryable error states for persisted External Agent tasks;
- synchronized README files, Chinese user manual, docs hub, PRD/HLD, Feature
  List, capability ledger, Known Issues, usage guide, changelog, feature/test
  guides, and in-app `kodax_manual`.
