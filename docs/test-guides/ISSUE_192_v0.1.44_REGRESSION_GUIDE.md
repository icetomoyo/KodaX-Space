# Issue 192 / v0.1.44 静默安全退出回归测试指南

## 功能概述

**问题**: 普通安全退出每次都会显示醒目的 Windows 系统通知

**目标版本**: v0.1.44

**测试日期**: 2026-08-19

**测试人员**: 待填写

修复后，用户主动执行普通安全退出时不再收到系统级横幅。应用内退出状态、托盘进度、
失败恢复以及需要用户决策的确认对话框保持不变。

## 测试环境

### 前置条件

- 使用包含本修复的 Windows v0.1.44 开发构建。
- Windows 通知功能处于开启状态，以确认 Space 没有发送退出通知。
- 托盘功能可用，并准备无任务、活跃任务和可制造 Runtime 清理失败的三种场景。

## 测试用例

### TC-001: 无任务时普通安全退出

**优先级**: 高

**类型**: 正向测试

**前置条件**:

- Space 和 Runtime 均无活跃任务。

**测试步骤**:

1. 打开 KodaX Space。
2. 从托盘或应用菜单选择“彻底退出”。
3. 观察应用内反馈、Windows 通知区域和进程退出结果。

**预期效果**:

- [ ] 应用立即显示短暂的安全退出状态并转入后台。
- [ ] Windows 不出现“KodaX Space 正在后台安全退出”系统通知。
- [ ] 清理完成后 Space 正常退出。
