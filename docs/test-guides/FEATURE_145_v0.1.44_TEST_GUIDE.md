# 跨平台应用图标数字角标 - 人工测试指导

## 功能概述

**功能名称**: Cross-Platform Attention Badge

**版本**: v0.1.44

**测试日期**: 2026-08-19

**测试人员**: [待填写]

**功能描述**: 当 KodaX Space 存在未读 Session 结果、待处理权限请求或 Ask User 请求时，在 Windows 任务栏/通知区域、macOS Dock 或受支持的 Linux launcher 图标上显示唯一 Session 数字角标。

---

## 测试环境

### 前置条件

- 使用 v0.1.44 的正式打包产物；开发模式仅用于安全用例的 IPC 验证。
- 至少准备两个可独立运行的 Session，并能触发成功、失败、权限请求和 Ask User 请求。
- Windows 测试需启用通知区域图标；macOS/Linux 测试不得关闭系统应用角标能力。

### 账号

- 无专用账号要求；使用可正常执行 Session 的本地配置。

### 平台要求

- Windows 11（100%、150%、200% 显示缩放）
- macOS 14 或更新版本
- Ubuntu 24.04 GNOME；另选一个不支持 Electron launcher badge 的 Linux 桌面验证降级

---

## 测试用例

### TC-001: Windows 后台完成结果显示并清除角标

**优先级**: 高

**类型**: 正向测试

**前置条件**:

- Windows 上启动 Space，任务栏图标可见，当前选中 Session A。
- Session B 没有未读标志。

**测试步骤**:

1. 在 Session B 启动任务，然后切回 Session A。
2. 等待 Session B 完成。
3. 观察任务栏图标；将 Space 关闭到通知区域后再观察通知区域图标。
4. 从通知区域恢复 Space，并打开 Session B。

**预期效果**:

- [ ] Session B 完成后任务栏图标显示红底白字 `1`。
- [ ] 关闭到通知区域后，通知区域图标右下角保持 `1`。
- [ ] 打开 Session B 后角标清零，任务栏覆盖被移除且通知区域恢复基础图标。
- [ ] 全程不出现窗口卡死、重复图标或错误弹窗。
