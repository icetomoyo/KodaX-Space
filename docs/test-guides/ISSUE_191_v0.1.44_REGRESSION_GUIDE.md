# Issue 191 / v0.1.44 External Agent Task List Regression Guide

## 功能概述

**问题**: 历史 Session 无外部任务时错误显示 `session not found`

**目标版本**: v0.1.44

**测试日期**: 2026-08-19

**测试人员**: 待填写

修复后，右侧栏“外部任务”应明确区分加载中、空列表、存在任务和可恢复失败四种状态。
只读列表不会恢复历史 Session 的 Runtime；真实存储失败仍可见且不会伪装成空列表。

## 测试环境

### 前置条件

- 使用包含本修复的 v0.1.44 开发构建。
- 准备一个从磁盘恢复、未调用外部 Agent 的历史 Coder Session。
- 准备一个至少包含两个外部任务的 Session。
- 可通过测试注入或断开任务存储访问来制造列表读取失败。

## 测试用例

### TC-001: 历史 Session 无外部任务

**优先级**: 高

**类型**: 正向测试

**前置条件**:

- 历史 Session 已持久化，Space 重启后尚未恢复其执行态。
- 该 Session 没有外部 Agent 任务。

**测试步骤**:

1. 启动 Space，并从历史列表打开该 Session。
2. 等待正文和右侧栏加载完成。
3. 展开“外部任务”区域。

**预期效果**:

- [ ] 标题显示“外部任务（0）”。
- [ ] 正文显示“本次运行没有调用外部 Agent”。
- [ ] 不出现 `session not found`、`HANDLER_ERROR` 或红色技术错误。
- [ ] 打开侧栏不会恢复 Provider/Runtime 执行态。

**实际结果**: 待填写

**是否通过**: [ ] Pass / [ ] Fail

### TC-002: 真实读取失败可恢复

**优先级**: 高

**类型**: 负向测试

**前置条件**:

- 已打开一个有效 Session。
- 可稳定制造外部任务存储读取失败。

**测试步骤**:

1. 制造读取失败并打开或刷新该 Session。
2. 观察“外部任务”标题和正文。
3. 恢复存储访问，点击“重试”。

**预期效果**:

- [ ] 标题显示“外部任务 · 暂不可用”，不显示错误的 0 计数。
- [ ] 正文说明“暂时无法加载外部任务”和“不会影响本次运行结果”。
- [ ] 不暴露 IPC 通道名、文件路径、堆栈或底层错误字符串。
- [ ] 恢复后点击“重试”进入加载态，并最终显示正确列表。

**实际结果**: 待填写

**是否通过**: [ ] Pass / [ ] Fail
