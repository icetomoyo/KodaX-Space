# FEATURE_142 v0.1.33 Human Test Guide

## 前置条件

- 打开一个包含可预览文本文件和已修改代码文件的项目。
- 会话中存在行内文件路径，例如 `` `docs/FEATURE_LIST.md` ``，以及普通 Markdown
  文件链接。

## 主流程

1. 左键点击可预览文件路径，确认仍按既有规则在 File Viewer 中打开。
2. 右键点击同一路径，确认菜单依次显示“在文件查看器中打开”“打开 diff”“插入
   @path”“复制相对路径”“在文件管理器中显示”。
3. 选择“在文件查看器中打开”，确认目标文件而非 Artifact 在 File Viewer 中打开。
4. 再次打开菜单并选择“打开 diff”，确认当前项目内的目标进入 diff 表面。
5. 选择“插入 @path”，确认输入框获得相对项目根目录的 `@path` 引用。
6. 选择“复制相对路径”，粘贴并确认内容是项目相对路径。
7. 选择“在文件管理器中显示”，确认系统文件管理器定位并选中目标文件。

## 边界回归

- 对允许范围内的绝对 Windows/macOS/Linux 路径重复主流程。
- 对 HTTP(S)、Partner 生成物链接和证据引用点右键，确认不出现本地文件动作菜单。
- 在视口右下角附近触发菜单，确认菜单不会溢出窗口。
- 打开菜单后按 Escape 或点击菜单外部，确认菜单关闭且不会触发文件动作。
- 切换中英文界面，确认菜单复用既有本地化文案且没有截断。
