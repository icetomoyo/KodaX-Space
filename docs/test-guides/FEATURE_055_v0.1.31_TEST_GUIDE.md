## 功能概述

**功能名称**: Packaged Renderer `app://space` Origin<br>
**版本**: `v0.1.31`<br>
**测试日期**: 2026-07-12<br>
**测试人员**: [待填写]

打包版主窗口和 Artifact 窗口从受信任的 `app://space/` 加载，只允许读取包内 renderer 资源；开发模式仍使用 Vite 地址。

## 测试环境

### 前置条件

- 使用 `npm run build:pack` 生成的 `out/win-unpacked/KodaX Space.exe`。
- 准备一个可打开的项目和至少一个 Artifact。
- 不需要 Provider 或网络。

## 测试用例

**类型**: 正向测试/安全测试
