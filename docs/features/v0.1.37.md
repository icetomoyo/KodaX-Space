# KodaX Space v0.1.37 — Recovery and Release Alignment

> Status: Released on 2026-08-06.
> Scope: maintenance release; no new numbered Feature is assigned.

## Version outcome

v0.1.37 is the next public maintenance baseline after v0.1.36.
Every formal Space workspace manifest is aligned to package version 0.1.37
and the exact npm Registry @kodax-ai/kodax@0.7.83 package.

The release carries the already-landed recovery and shutdown stabilization
work. This release preparation does not add or alter system business logic.

## Delivered scope

### Multi-Session recovery

Session hydration, history paging, live projection, and Runtime observation
preserve project, surface, Session, request, and Runtime identity while a user
switches Sessions or resumes persisted work. Stale snapshots and late events
remain bounded to their original owner.

### Safe close and Runtime recovery

Complete exit keeps its progress surface available until shutdown is
authoritatively verified. If Runtime control has already closed and recovery
cannot be proven, Keep Open uses a controlled relaunch instead of reopening an
invalid Coder admission path.

### Published dependency and manual alignment

Root/Desktop manifests, both workspace lock views, installed package bytes,
runtime compatibility reporting, user documentation, and kodax_manual all
describe KodaX 0.7.83 and the v0.1.37 recovery boundary. The manual continues
to inherit the installed SDK's underlying mechanism topics instead of copying
an SDK manual into a stale Space fork.

### Release-only verification

The compatibility expectation for the installed package is updated in tests.
The semantic bootstrap surface change is presentation-only. No system business
logic is introduced by the release preparation.
