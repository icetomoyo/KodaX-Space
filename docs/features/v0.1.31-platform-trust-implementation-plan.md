## 1. Decision

F055 and F069 move from `v0.1.32` into the consolidated `v0.1.31` release. They are implemented before broad F120 rollout so the semantic-control plane boots from a standard application origin and produces safe local diagnostics, but neither feature may weaken or block F120 when its optional integration is unavailable.

Implementation order:

1. F055 pure path/origin contract and Electron scheme registration;
2. F055 window/navigation/CSP migration and packaged smoke;
3. F069 pure redaction/serialization/rotation core;
4. F069 early bootstrap, renderer envelope, export service, and Settings entry;
5. direct structured events for Runtime and F120 boundaries;
6. combined release verification.

## 4. F055 security contract

The pure resolver receives a request URL and renderer root, then:

1. requires scheme `app:` and host `space` exactly;
2. rejects username, password, port, query, malformed percent encoding, backslash, encoded separator, NUL/control character, and non-rooted paths;
3. maps `/` to `/index.html` and otherwise decodes one canonical path;
4. normalizes with POSIX semantics and rejects `.`/`..` ambiguity;
5. resolves the filesystem candidate below the renderer root;
6. resolves real paths for the root and candidate and rejects symlink/alias escape;
7. serves regular files only, never directories;
8. returns explicit not-found/forbidden/bad-request results without leaking filesystem paths.

Tests cover Windows drive roots through injected path helpers while remaining runnable on every platform.

## 7. F069 storage and rotation

- Root: `<userData>/diagnostics/` so Electron profile isolation and OS permissions apply.
- Active log: `space-main.jsonl`.
- Maximum active size: 5 MiB.
- Retention: five rotated files, oldest removed first.
- Individual record: 16 KiB after redaction and serialization.
- Write queue: bounded; overflow increments one dropped-count field reported by the next successful record.
- Rotation uses close/rename/reopen within the diagnostics root. Initialization and write failures fall back to original console output without recursion.

## 8. F069 redaction contract

Always redact:

- keys matching token/key/secret/password/authorization/cookie/credential families;
- bearer/basic authorization material and token-shaped values;
- URL userinfo and secret-like query parameters;
- values equal to configured secret environment variables;
- prompt, message body, tool input/output, document/file content, clipboard, and transcript fields;
- home/profile absolute prefixes when they appear in safe error metadata.

Allow only bounded primitives, arrays, and plain objects. Replace functions, buffers, errors, circular values, and deep/unbounded objects with safe summaries. Error stack is stored only in development and is path-redacted; production records category/name plus a bounded safe message.

## 9. F069 export contract

The export ZIP contains at most:

- `manifest.json`: format version, Space/KodaX versions, platform, included categories, generated time, truncation/degradation notices;
- `logs/*.jsonl`: redacted recent main logs within per-file and total caps;
- `capabilities.json`: existing redacted Runtime ownership/capability snapshot;
- `release.json`: updater/channel/version facts;
- `known-degradations.json`: stable reason codes, never raw task text.

The renderer requests export but cannot supply a path. Main displays the native save dialog, generates the bundle in memory under a total cap, and writes atomically to the user-selected destination. Cancellation is a normal typed result.

## 12. Rollback

- F055 is a binary release boundary: one running process uses either the complete `app://space` path or the prior package; never mix origins after startup.
- F069 file/export sinks can be disabled through an internal bootstrap flag while keeping bounded stderr/console diagnostics.
- Disabling F069 never disables Runtime or F120 behavior.
- Existing logs are never uploaded and remain subject to retention after rollback.

## 13. Completion record

- F055 serves packaged renderer assets only from exact `app://space/`, with traversal, encoding, authority, directory, missing-file, and alias-escape tests.
- F069 initializes a bounded rotating JSONL sink before application startup work, bridges legacy console output, emits direct Runtime/Workflow/updater/F120 events, and exports an explicit redacted ZIP from Settings.
- `SPACE_DISABLE_DIAGNOSTIC_FILE_SINK=1` is the local rollback gate: it keeps normal stderr/console diagnostics and the reviewed export contract available while disabling JSONL persistence and the legacy-console file bridge.
- Scoped ESLint enforcement prevents raw console use in the new diagnostics, semantic-control, protocol, and IPC modules outside the reviewed console bridge.
- Full unit tests, TypeScript, ESLint, production build, Windows package content checks, and packaged boot from `app://space/` passed. Electron E2E passed 57/58 on the first run; the sole existing Partner mock-response timeout passed immediately on isolated retry.
