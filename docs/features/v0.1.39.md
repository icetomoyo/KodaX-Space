# v0.1.39 Maintenance Design

## Actor settlement convergence

Space consumes, but does not recreate, KodaX Actor durability truth. The Coder
Runtime must advertise `actorSettlementConvergence:1`, proving root fail-closed
fencing, automatic exact-owner repair, safe after-turn admission behind unknown,
and failed terminal semantics when no stronger pre-fence fact exists. KodaX
0.7.85 also fences new Runtime callbacks and effects after the durability
boundary and keeps the Session route occupied until exact pre-fence
Runtime-mediated tool effects settle; it does not trust or wait forever for an
abort-ignoring provider Promise.

The same Runtime must advertise `sessionEventJournal:1`. Space preserves the
complete `(sessionId, journalEpoch, seq)` cursor, compares sequence numbers only
inside the same Session journal lineage, and treats an epoch change as a fresh
lineage. This prevents another Session's sequence or a daemon restart from
pinning a stale active projection or an acknowledged send.

Space owns four user-facing invariants:

1. `unknown` remains active: spinner and Stop stay visible until a Runtime
   terminal event arrives.
2. Keyboard, button, Slash, and Skill sends become after-turn input while the
   visible Run is unknown. Space never replays a rejected draft automatically.
3. Stop carries the visible exact Run ID and validates the returned Run/Session
   identity, so a stale UI action cannot cancel a successor.
4. A terminal event cannot erase a newer live query/output turn merely because
   canonical Session persistence is incomplete. Pruning requires exact
   canonical folding proof for that turn.
5. Ambiguous sends retain their operation identity until factual settlement.
   Retrying the exact query,
   including after another draft was attempted, reuses its admission identity;
   main-process deduplication runs before attachment validation and cleanup.

No force-idle, automatic input replay, or ownership takeover is introduced.
Foreign ownership and permanent storage ambiguity continue to fail closed.

The exact npm Registry KodaX 0.7.85 package is now pinned in both Space
manifests and every lockfile view. Production Windows packaging, package smoke,
and packaged boot smoke pass against those exact Registry bytes; final Issue
178 release qualification still requires the packaged Windows fault-injection
guide.
