# KodaX Space v0.1.38 — KodaX 0.7.84 Maintenance Release

> Status: Released on 2026-08-07.
> Scope: maintenance release; no new numbered Feature is assigned.
> Source of truth: this file, the [release-readiness record](../releases/v0.1.38-release-readiness.md), and the current tests.

## Version outcome

Space v0.1.38 aligns every formal workspace package and runtime capability
contract to package version `0.1.38` and consumes the exact npm Registry
`@kodax-ai/kodax@0.7.84` package. The lockfile records the published tarball
and SRI rather than a local SDK build.

This release preparation does not add or alter system business logic. It
updates release metadata, documentation, manual projections, and test fixtures;
the Session recovery and KodaX runtime changes included in the release were
already landed and are preserved for verification.

## Delivered scope

### KodaX 0.7.84 runtime contract

The release documents the published SDK contract used by Space:

- bounded Agent progress persistence and exact same-owner Stop reconciliation;
- late Actor settlement recovery before applying a captured executor result;
- fail-closed behavior for foreign ownership, missing ownership, and persistent
  storage failures;
- the existing durable managed-Run, Session identity, Runtime safety, and
  integration resilience contracts.

Space continues to negotiate capabilities explicitly and does not infer
lifecycle support from the KodaX semantic version.

### Session reactivation correction

An invalidated but already-rendered active Session retains its resolved
projection while an open Run overtakes canonical history recovery. The
canonical refresh cannot duplicate, reattach, or move the newest query or
answer within the transcript. Issue 176's identity- and state-based regression
coverage is carried forward for v0.1.38.

### Release and documentation alignment

Root/Desktop manifests, workspace package metadata, lockfile views, runtime
version reporting, README files, the Chinese user manual, the capability
ledger, known issues, release records, regression guide, and in-app
`kodax_manual` describe the same Space/KodaX pair. The tracked Windows icon
resource is included in the package presentation path.
