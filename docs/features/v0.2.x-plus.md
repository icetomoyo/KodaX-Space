# KodaX Space Post-v0.2.x Transcript Scale Hardening

> Status: Planned, after completion of the `v0.2.x` product line
> Product owner: KodaX Space
> SDK gate: None; KodaX already owns canonical conversation paging, ordering, immutable revisions, resynchronization, and exact history boundaries

## Version objective

Preserve the current newest-first loading and natural upward extension while making renderer work independent of how many historical rows the user has accumulated. This version does not change transcript meaning, visibility, ordering, or persistence; it replaces browser-only occlusion with a true bounded-DOM presentation layer.

## FEATURE_144: Windowed Continuous Transcript Virtualization

### 1. 需求概述

After a user repeatedly loads older pages, tens of thousands of canonical messages must remain reachable through one continuous transcript without keeping every row mounted. The visible result must behave like the current natural scroll surface rather than page switching: older content grows upward, the live tail remains at the bottom, and the user's current reading position does not jump.

### 2. 影响范围

- Coder and Partner conversation rendering, history paging state, viewport anchoring, and long-Session cache lifecycle.
- Dynamic-height user/assistant Markdown, thinking and tool groups, artifacts, notices, images, code blocks, and expanded/collapsed receipts.
- Query rail and transcript search navigation, jump-to-bottom, keyboard/touch/wheel scrolling, and accessibility focus.
- Fork and rewind selectors with their exact canonical history boundaries.
- Active streaming tails, queued inputs, observation recovery, compaction boundaries, and history/live reconciliation.
- Performance diagnostics and packaged Windows/macOS/Linux acceptance corpora for large Sessions.

The feature does not change KodaX transcript storage, canonical ordering, cursor semantics, raw audit retention, or Space's strong-identity-only reconciliation policy.

### 3. 技术方案

- Keep the accumulated canonical page model and its stable logical row identities, but mount only the viewport plus bounded overscan in either direction.
- Represent unmounted prefixes and suffixes with measured/estimated space so the native scrollbar remains continuous. Dynamic measurements must update without moving the active canonical viewport anchor.
- Make height changes, row regrouping, expansion, image/Markdown completion, viewport resize, and delayed font/layout work revision-safe and cancelable by genuine user navigation.
- Navigation targets outside the mounted window resolve through canonical indexes and paging state, load missing history when required, then materialize and focus the target without scanning or mounting the full transcript.
- Keep the live tail outside destructive window replacement. Historical window movement must not duplicate, delete, reorder, or content-match canonical history and live records.
- Select or implement the virtualizer only during the implementation plan, after validating dynamic-height, reverse/prepend, accessibility, Electron/Chromium, and licensing constraints. This design does not preselect a library.

### 4. 接口契约

- KodaX remains authoritative for newest/older canonical pages, cursor and revision/source-revision fences, `data_changed` resynchronization, conversation status/issues, and exact fork/rewind boundaries.
- Space owns the accumulated page index, row projection, measurements, mounted window, overscan, anchor restoration, navigation, and diagnostics.
- Every mounted row is addressed by stable canonical identity. Timestamp, equal content, visual position, or page-local index must never be used to reconcile records.
- A Session switch, paging lifecycle replacement, resync, or user-owned navigation invalidates stale measurement/restoration work before it can move the viewport.
- Search, query navigation, fork, and rewind must resolve against the full accumulated canonical model, not merely the currently mounted DOM.

### 5. 实现步骤

1. Capture packaged baselines for 1k, 10k, and at least one larger mixed-height transcript, including DOM count, layout/paint time, memory, scroll anchoring, search, and live-tail behavior.
2. Extract a renderer-independent canonical row index and dynamic measurement cache from the current continuous-prepend path.
3. Introduce bidirectional window calculation, bounded overscan, prefix/suffix spacers, and stable-anchor restoration behind a development gate.
4. Integrate dynamic-height invalidation for Markdown, tools/thinking expansion, images, fonts, resize, and page-seam regrouping.
5. Route search/query jumps, jump-to-bottom, keyboard/touch/wheel input, fork/rewind, and accessibility focus through the logical row index.
6. Prove active streaming, queued input, compaction, observation resync, `data_changed`, Session switching, and cache eviction cannot revive stale windows or lose the live tail.
7. Run cross-platform packaged performance and correctness gates before replacing the current `content-visibility` fallback.

### 6. 验收标准

- Loading at least 10,000 mixed-height conversation rows keeps mounted `conversation-render-row` nodes at or below 500; the bound is independent of accumulated history length.
- Repeated older-page loads preserve one continuous scrollbar and the active canonical row within 2 px after dynamic layout settles; there is no page swap or forced return to the newest page.
- Scrolling in either direction, jumping to newest, and returning to an earlier reading position never produces a blank window, duplicate row, reordered row, or stale-page flash.
- Expanding/collapsing tools and thinking, delayed Markdown/image/font layout, viewport resize, and live streaming preserve the intended anchor and remain immediately cancelable by real user input.
- Search and query navigation can locate targets outside the mounted window, loading older pages only when necessary. Fork and rewind use the exact target boundary even when its row was initially unmounted.
- Active and queued Runs retain spinner, Stop, interactions, live tail, and observation recovery semantics while historical DOM remains bounded.
- Packaged Windows, macOS, and Linux acceptance records DOM bound, heap trend, first paint, page-prepend latency, anchor drift, and long-scroll frame responsiveness; regressions fail the feature gate rather than silently falling back to full mounting.
